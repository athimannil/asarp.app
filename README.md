# Asarp Bot - Telegram Group Management Bot

Asarp Bot is a powerful Telegram bot designed to automate group management, moderation, and member engagement. It helps administrators maintain clean, safe, and organized communities without constant manual intervention.

Asarp Bot is your 24/7 automated group assistant that handles:
- **Spam & Content Moderation** - Automatically removes spam, inappropriate content, and enforces group rules

and other features
